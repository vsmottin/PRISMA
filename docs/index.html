Projeto PRISMA

Processador RISC-V Interativo para Simulação e Modelagem de Arquitetura

O projeto PRISMA traz implementações de um processador RISC-V RV32I que usam o Logisim Evolution como base.

Os processadores

Derivações de modelo do mesmo conjunto de instruções.

Monociclo

Uma instrução executada por ciclo de clock.

Pipeline

Cinco estágios, separados por bancos de registradores.

Os blocos funcionais

Cada bloco é um circuito independente, com manual próprio, importado como biblioteca pelos processadores.

Controle

  • ucPrincipal - gera os sinais de controle
  • ucULA - define a operação da ULA
  • ucDesvio - decide os desvios condicionais
  • ucEnderecamento - controla o endereçamento

Cálculo e dados

  • ULA - realiza as operações lógicas e aritméticas
  • bancoRegistradores - os 32 registradores
  • decodificador - fatia a instrução em campos
  • extensores - extensão de sinal e de zero
  • zero - indica resultado nulo da ULA
  • contadorCiclos - conta os ciclos executados

Memórias

  • memInstrucoes - guarda o programa
  • memDados - faz leitura e escrita de dados

Pipeline

  • estagiosPipeline - as quatro barreiras entre estágios
  • idULA - resolve desvios antes da execução

Programas para executar

Arquivos em linguagem de máquina, prontos para carregar na memória de instruções. Os do grupo pipeline já trazem as bolhas (nop) necessárias e também rodam no monociclo.

Planos de aula

Quatro atividades práticas de laboratório, cada uma com plano de aula e guia do aluno.

  • E1 Compreensão da mudança de estado no processador
  • E2 Geração manual dos sinais de controle
  • E3 Dedução de hazards e redução de bolhas
  • E4 Diagnóstico de falha no caminho de dados
